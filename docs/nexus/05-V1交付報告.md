### 實測找到並修好的問題

## 4. 已知限制

1. **跨電腦未實測**：防火牆、真實網卡選擇只有自動測試（127.0.0.1）與程式碼審查。有第二台家用電腦時請照說明書再跑一次。
2. TOFU：第一次連線要靠人核對指紋前 8 碼。
3. DPAPI 只擋其他 Windows 帳號，不擋同帳號的惡意程式。
4. 兩台時鐘差超過 5 分鐘連不上（會顯示 `CLOCK_SKEW`）。
5. EXE 沒有程式碼簽章（Windows SmartScreen 會警告）。

## 5. 使用情境結論

- 使用者目前只有一台家用電腦；學校電腦**不建議**當節點（要裝 VPN 才連得到、學校使用規定、成人網站工具放在學校網路上的風險）。
- 所以 V2 的「至少兩個 Worker」驗收，規劃用**同一台電腦開兩個 Worker**（`--worker --profile 名稱`，各自獨立身分與資料夾），見 `06-V2技術規格.md`。

## 6. 執行方式

- Master：`VideoHelper.exe` → ③ 設定 → ⚙ 進階設定 → 🖧 節點 → 勾「啟用 Master」
- Worker：`VideoHelper.exe --worker`（無視窗測試：`--worker --headless --master URL --pair 碼 --name 名稱`）
- 資料：`%APPDATA%\VideoHelper\nexus\master\`（nexus.db、pki、master.log）、`…\nexus\worker\`（state.json、金鑰、worker.log）
