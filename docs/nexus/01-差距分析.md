# Nexus Phase 2：差距分析（Gap Analysis／需求追溯矩陣）

狀態定義（規格 25.1 Phase 2）：
**Existing**＝已有且符合要求；**Partial**＝有雛形但不符合規格要求；**Missing**＝完全沒有；**Blocked**＝受平台／架構限制，第一版做不到或只能部分做到（附證據與替代方案）。
「證據」欄指 `video_helper_app.py` 的位置或檔案。V 欄＝規格第 22 節排定的版本。
