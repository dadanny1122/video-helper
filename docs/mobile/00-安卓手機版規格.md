# Video Helper 安卓手機版規格（草稿 v0.1）

> 2026-11-20｜狀態：**已確認**（第 6 節）；M1 等手機到了再開工
> 背景：使用者之後要換 Google Pixel（10 或 11，256GB），想讓專案在安卓上也能用。
> 原本 CLAUDE.md 寫的是「之後換三星」，改成 Pixel；iPhone 相容層（v3.17.0～3.18.0）保留不動。

## 1. 目標（白話）

1. 手機用 **Firefox＋暴力猴** 打開影片網站時，擋廣告、盾牌、畫質清單、下載都跟電腦一樣好用，而且手指好按。
2. Pixel 的 **Linux 終端機**（Debian 虛擬機）裡可以用一個小工具下載影片，不用帶電腦。
3. 全部還是在自己的裝置上跑，不新增伺服器。

## 2. 不做的事

- 不做 APK／上架 Play 商店（要簽章、審核，成人內容也上不了）。
- 不把手機當 Nexus 節點（會休眠、發熱；Nexus 用的 DPAPI、Job Object 只有 Windows 有）。
- 不讓電腦版對區域網路開放 Bridge（目前只聽 127.0.0.1，改了等於開新的攻擊面）。手機「交給電腦版」要等以後另外評估。
- 規則照舊：盜版轉載站、付費平台只擋廣告不下載；來源不明、無法確認同意的網站不做。

## 3. 現況（已經有的）

| 項目 | 手機上的情況 |
|---|---|
| 腳本 `@match`、擋廣告 | 跟電腦共用，理論上 Firefox 安卓版可直接跑（**待實機驗證**） |
| 下載 | 有 `GM_download` 就直接存；沒有就走 v3.18.0 的備用法（「開啟影片檔」／「在這頁下載」） |
| 面板拖曳 | 已經用 pointer 事件（手指也能拖） |
| 老闆鍵 | 只有鍵盤 Esc → **手機沒有 Esc，要新做** |
| 交給電腦版 | 連 127.0.0.1，手機上一定失敗 → **手機上要藏起來** |
| 按鈕大小 | 照滑鼠設計（約 20px 高），手指不好按 |

## 4. 分三期

### M1：腳本手機適配（先做，改腳本 → @version +1）

- **判斷是不是手機**：`matchMedia('(pointer:coarse)')`＋螢幕寬度，不看 userAgent（會被偽裝）。設定裡可以手動切「手機模式：自動／開／關」。
- **按鈕放大**：手機模式下可點的東西至少 40px 高、間距加大；面板預設貼右下、不擋播放鍵。
- **手機老闆鍵**：「**三指點一下**」和「**快速點兩下盾牌**」兩個都開（已確認），觸發後跟 Esc 一樣（靜音＋切偽裝頁）。
- **藏掉「交給電腦版」**：手機模式下不顯示，改顯示一行「手機上請用直接下載」。
- **下載**：先實機測 Firefox 安卓版的暴力猴有沒有 `GM_download`；沒有就自動走現有備用法。下載完提示「檔案在：下載」。
- **測試**：Playwright 用手機模擬（Pixel 尺寸、`hasTouch`）測面板、按鈕大小、老闆鍵手勢；真網站由你在手機上驗收。
- 不新增任何網路連線 → SECURITY.md 只需補一句手機說明。

### M2：Pixel Linux 終端機下載工具（M1 驗收後）

- 新的單一檔案 `vh_mobile.py`（不碰電腦版），在 Debian 裡跑：`python3`＋`yt-dlp`＋`ffmpeg`（apt／pip 安裝，版本鎖住）。
- 用法：`python3 vh_mobile.py <影片網址>` → 存到跟安卓共用的「下載」資料夾（路徑**待實機確認**）。
- **共用網站清單**：把「支援下載的網站」抽成一個 JSON 檔（例如 `sites.json`），電腦版和 `vh_mobile.py` 都讀它；GitHub 測試自動檢查兩邊一致。白名單外的網址直接拒絕，並說明原因。
- 沿用電腦版的失敗分類（等重試／需要處理／空間滿）和 429 冷卻，邏輯盡量共用。
- 誠實標示：Linux 終端機是 Google 的「實驗性」功能，系統更新後可能改變。
- 會連網 → 同步更新 SECURITY.md 和 `.github/net_test.py` 的 ALLOWED。

### M3：以後再評估（現在不做）

- 手機把網址「丟給」家裡電腦下載（要 Bridge 開到區域網路＋配對＋加密，等同 Nexus 等級的安全設計）。
- 手機 GUI（Linux 終端機已經能跑圖形程式，但還不穩）。

## 5. 驗收標準

- M1：Pixel＋Firefox 開 Pornhub、XVideos、Jable 各一部：盾牌出現、廣告擋掉、能選畫質、下載成功存進「下載」；老闆鍵手勢有效；看不到「交給電腦版」。
- M2：終端機裡下載 2 個支援網站的影片成功；白名單外網址被拒絕；斷網時顯示「等重試」。
