## 2. 做法

- **字典**：中文原文當「鑰匙」、英文是翻譯（找不到翻譯就顯示中文，不會壞掉）
  - 新介面：`webui/i18n.js`（打包時一起合成一頁）；畫面上固定的字在啟動和換語言時整頁換一次，動態的字用 `t('…')`
  - 電腦版 Python：`i18n/en.json` 給回傳到網頁的訊息、系統匣、小視窗用 `t("已加入 {n} 部", n=3)`；跟網頁共用同一份
  - 腳本：單一檔案的規定不變 → 字典直接寫在腳本裡（`I18N_EN`），`T('…')`
- **測試**：
  - 自動檢查「畫面上的中文字在英文模式下還剩幾個」（Playwright 開英文版，掃所有看得到的文字，有中文就列出來，0 個才算過；網站來的影片標題除外）
  - 電腦版：Python 裡送給網頁的訊息都要有翻譯（掃 `t("…")` 的鑰匙都在字典裡）
  - 腳本：現有的隱私測試、攻擊模擬再用英文模式各跑一次

## 4. 風險

- 字數多（腳本約 470 行有中文、電腦版新介面約 300 句、Python 訊息約 150 句），第一版難免有漏翻 → 靠「英文模式掃中文字」的測試抓
- 英文通常比中文長，按鈕、卡片可能擠 → 英文版每頁截圖檢查排版
- 之後每次加新功能，中英文都要寫（我會照用詞表一起加）

## 5. E1 做法紀錄（電腦版 v1.44.0）

- 字典 `webui/en.json`：`exact`（整句）、`patterns`（`{a}` 是空格，例：`已加入 {a} 部` → `Added {a} videos`；空格裡的字會再翻一次）、`ignore`（不是畫面上的字）
- 翻譯規則（`webui/i18n.js` 和 `webui/i18n.py` 一模一樣，`i18n_check.py` 會核對）：整句 → 有中文字的樣板 → 拿掉前後標點再找 → 多行就一行一行翻 → 用 ｜・；。切開分別翻 → 只有標點的樣板（`{a}：{b}`）→ 都不行就照原文
- 網頁：英文模式用 MutationObserver 把畫面上的中文換掉（app.js、電腦版送來的訊息都不用改寫法）；網站來的字放在 `translate="no"` 裡；切回中文會還原
- 電腦版：`T()` 給系統匣、通知；messagebox／filedialog 自動翻；`float_dialog` 開的小視窗用 `tk_translate()` 每 0.7 秒換一次
- `settings["lang"]`：auto／zh／en；auto 看 Windows 顯示語言（`GetUserDefaultUILanguage`，中文＝zh）
- 測試：`.github/i18n_check.py`（從 index.html、app.js、電腦版會顯示的函式、nexus 的狀態和錯誤訊息抓出所有中文，翻完還有中文就失敗；也比對 JS／Python 結果）、`.github/webui_i18n_test.js`（英文模式每頁、每種對話框掃中文、截圖、切回中文還原）、`webui_host_test.py`（語言設定、系統匣字、對話框、小視窗）
- **之後加新的中文字**：跑 `python3 -I .github/i18n_check.py`，把列出來的加進 `webui/en.json`（照附錄用詞）
- 沒翻：節點那台的小視窗（`--worker`）、以前的視窗（`--classic`）、錯誤日誌、更新紀錄

## 6. E2 做法紀錄（腳本 v3.23.0）

- 字典寫在腳本裡（單一檔案）：`const I18N_EN = /*I18N_EN*/{…}/*END_I18N_EN*/`；翻譯引擎在 `// I18N-ENGINE-START`～`END` 之間，規則跟電腦版一樣（`i18n_check.py` 會抓出來跟 Python 對照）
- 語言：`store` 的 `lang`（auto／zh／en）；auto＝`navigator.language` 是 zh 開頭就中文；盾牌面板「🌐 English／🌐 中文」、暴力猴選單切換（會重新整理網頁）
- 只翻腳本自己的畫面：每個 `class="vh-ui"` 元素建立時 `vhWatch(el)`（MutationObserver 只看那一塊），網頁本身的字完全不碰
- `T()`：暴力猴選單（`gmMenu` 自動翻）、對話框（`vhAlert`／`vhConfirm`／`vhPrompt`，配對用 `SAFE.prompt(T(…))`）、分頁偽裝標題、攔截紀錄
- 不翻：Console 紀錄、跳過廣告用來比對網站按鈕的字（跳過、略過…）
- 測試：`.github/userscript_i18n_test.js`（英文瀏覽器：盾牌、功能開關、狀態檢查、下載清單、選單、對話框都沒有中文；網頁本身的中文沒被動；中文瀏覽器／手動選中文還是中文）；隱私測試、攻擊模擬中英文各跑一次（`VH_LOCALE=en-US`）
- **之後改腳本的中文字**：跑 `python3 -I .github/i18n_check.py`，漏翻的加進腳本裡的 `I18N_EN`
