## 2. 架構

```
VideoHelper.exe
 ├─ 後台（不動）：Queue／下載／AI 字幕／Bridge／Nexus MasterService
 ├─ 新：ui_bridge.py  ── 把後台包成一組「動作」和「事件」
 │     動作（JS 呼叫）：enqueue(url, 畫質)、pause_all、cancel(id)、open_file(id)、history(…)、settings_get/set、nexus_* …
 │     事件（推給 JS）：每 0.5 秒一包狀態（任務進度、速度、節點、通知），只送有變的
 └─ 新：ui/  index.html＋app.css＋app.js（打包進 EXE；不載入任何外部網址）
```

- 舊介面（Tkinter）和新介面共用同一個 `ui_bridge`，所以兩邊看到的狀態一樣。
- JS 只能呼叫白名單裡的動作；每個動作在 Python 這邊檢查參數（例如網址一樣只收支援的網站）。

## 3. 安全

- 網頁只載入 EXE 裡的本機檔案；**CSP 禁止連外**（`default-src 'self'`），不載入任何 CDN、字型、圖片網址。
- 關閉 WebView2 的開發者工具、右鍵選單、拖放檔案開網頁、新視窗；點到外部連結一律用系統瀏覽器開。
- 縮圖、檔案路徑只透過 `open_file(id)` 這種「用任務編號」的動作打開，JS 拿不到任意路徑。
- 沒有新增任何對外連線 → `net_test.py` 的允許清單不變。
- WebView2 沒裝（很舊的 Windows 10）→ 自動退回舊介面，並提示可以去微軟官網裝。

## 6. 風險

- **WebView2 第一次開比較慢**（約 0.5～1 秒）：先顯示一個簡單的載入畫面。
- **EXE 變大**：pywebview 在 Windows 要 pythonnet；PyInstaller 會把沒用到的介面套件也打包進去，要在 build.yml 排除。預估多 5～15 MB，第 1 段量完跟你說。
- 這是大工程，4 段做完前，Tkinter 和新介面要同時維護；所以第 4 段之後就移除舊版，不長期並存。
