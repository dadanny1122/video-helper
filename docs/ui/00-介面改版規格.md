# 電腦版介面改版規格（新介面 V5）

> 2026-11-24｜狀態：**U1～U8 已確認（照建議）**；第 1 段＝電腦版 v1.36.0（見第 7 節）。
> 已確認：用網頁技術（WebView2）做介面；分 4 段做，舊介面在過渡期可以切換。
> 參考圖：使用者 2026-11-24 給的設計圖（左側選單＋上方 4 張數據卡＋下載任務列表＋右側 Nexus 狀態＋最新消息＋快速功能）。

## 0. 一句話

**只換「畫面」，不換「後台」**：下載佇列、yt-dlp、AI 字幕、Bridge、Nexus 全部照舊；新畫面用 HTML／CSS／JS 畫，透過一條本機橋接跟 Python 講話。

## 2. 架構

```
VideoHelper.exe
 ├─ 後台（不動）：Queue／下載／AI 字幕／Bridge／Nexus MasterService
 ├─ 新：ui_bridge.py  ── 把後台包成一組「動作」和「事件」
 │     動作（JS 呼叫）：enqueue(url, 畫質)、pause_all、cancel(id)、open_file(id)、history(…)、settings_get/set、nexus_* …
 │     事件（推給 JS）：每 0.5 秒一包狀態（任務進度、速度、節點、通知），只送有變的
 └─ 新：ui/  index.html＋app.css＋app.js（打包進 EXE；不載入任何外部網址）
```

- 舊介面（Tkinter）和新介面共用同一個 `ui_bridge`，所以兩邊看到的狀態一樣。
- JS 只能呼叫白名單裡的動作；每個動作在 Python 這邊檢查參數（例如網址一樣只收支援的網站）。

## 3. 安全

- 網頁只載入 EXE 裡的本機檔案；**CSP 禁止連外**（`default-src 'self'`），不載入任何 CDN、字型、圖片網址。
- 關閉 WebView2 的開發者工具、右鍵選單、拖放檔案開網頁、新視窗；點到外部連結一律用系統瀏覽器開。
- 縮圖、檔案路徑只透過 `open_file(id)` 這種「用任務編號」的動作打開，JS 拿不到任意路徑。
- 沒有新增任何對外連線 → `net_test.py` 的允許清單不變。
- WebView2 沒裝（很舊的 Windows 10）→ 自動退回舊介面，並提示可以去微軟官網裝。

## 5. 驗收（每段都要你實機看）

- 畫面跟設計圖的感覺一致、深淺色都正常、150% 縮放字不糊
- 拖動、縮放、切頁順
- 開新版下載一部影片：進度、暫停、繼續、完成後縮圖、打開檔案都正常
- 切回舊版一切照舊

## 6. 風險

- **WebView2 第一次開比較慢**（約 0.5～1 秒）：先顯示一個簡單的載入畫面。
- **EXE 變大**：pywebview 在 Windows 要 pythonnet；PyInstaller 會把沒用到的介面套件也打包進去，要在 build.yml 排除。預估多 5～15 MB，第 1 段量完跟你說。
- 這是大工程，4 段做完前，Tkinter 和新介面要同時維護；所以第 4 段之後就移除舊版，不長期並存。

## 7. 實作紀錄

### 第 1 段（v1.36.0）
- `webui/`：`index.html`＋`app.css`＋`app.js`（合成一頁用 `html=` 塞進視窗）、`__init__.py`（`available()` 查登錄檔的 WebView2、`Host`、`Api` 只有 state／static／act／ready、`ACTIONS` 白名單、`parse_changelog`）
- 執行緒：pywebview 規定主執行緒 → `webui.run(start_app)`；App＋Tk 在 `webview.start(func)` 的執行緒；網頁的動作 `Host.act` → `App.q`（`on_web_action` → `web_<動作>`），等最多 5 秒拿回一句提示
- App：`settings["ui"]`（classic／web）、`web_attach`（藏原本的視窗、25 秒沒載入 → `_web_watchdog` 退回）、`web_publish`（每 0.5 秒一份 JSON）、`web_use_classic`、`on_web_close`（關視窗規則同 `on_close`，用網頁對話框問）、通知 `add_notice`、還沒做的頁 `web_old` 打開原本的視窗
- 縮圖（U3）這段先用網站縮寫的色塊，第 2 段再接 ffmpeg 截圖
- 測試：`.github/webui_test.js`（security.yml，Playwright＋假 api）、`.github/webui_host_test.py`（build.yml；`--real` 在 Windows 真的開 WebView2 截圖，artifact `webui-shots`）、selftest 檢查打包了網頁檔和 pywebview

### 第 2 段（v1.37.0）
- 網頁：`page-home`／`page-dl` 兩頁（`go()`）；新增下載（一個網址 `analyze` → `state.analysis` 畫質清單 → `enqueue_fmt`；多行 `add_batch` 帶畫質上限）、佇列（`clear_finished`）、紀錄（`api.history(查詢)` 搜尋／網站／狀態、勾選 `subtitles`／`delete_hist`、右鍵選單、雙擊）
- Api 多 `history`、`thumbs`（共 6 個）；`Host.hist`／`files` 由 `web_publish` 在 `History.version` 變了才重做
- 縮圖（U3 改法）：迷你 ffmpeg 沒有影片解碼器，改用 Windows 檔案總管的縮圖（`webui/thumbs.py`：`IShellItemImageFactory::GetImage` 只要縮圖 → 16:9 192×108 JPEG，存設定資料夾 `thumbs\`，一條 COM 執行緒；全黑／全白當作沒有）；不加新的解碼器、不連網
- `float_dialog()`：新介面時原本的視窗藏著，配對、AI 字幕小視窗改成先跳到最上面

### 第 3 段（v1.38.0）
- 網頁：`page-set`（6 張卡片，`data-set` 控制項 → `act("set", {key, value})`，`renderSettings` 在使用者正在打字時不覆蓋）、`page-setup`（`setup_step`）；頁面清單 `PAGES`、`go()`
