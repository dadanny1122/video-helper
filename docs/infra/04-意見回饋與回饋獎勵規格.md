# 意見回饋＋回饋獎勵 — 規格（2026-11-26 使用者確認：F2～F5 照建議；程式完成，等 Worker 設定）

使用者要求：電腦版和腳本都能寫意見回饋，送到 Discord；回饋後可以拿到好處；
**中文要超過 15 個字、英文要 20 個單字以上**才能送出。好處四種都要：限定主題配色、支持者徽章、搶先試用新功能、Discord 身分組。

## 1. 使用流程
1. 電腦版左邊選單多一頁「💬 意見回饋」；腳本盾牌面板多一顆「💬 意見回饋」
2. 選類型（建議／問題／稱讚／其他）、寫內容；下面即時顯示「還差 N 個字／N 個單字」，不夠就不能按「送出」
3. 送出 → 經過你的 Cloudflare Worker → Discord 新頻道 **#意見回饋**
4. 成功後顯示「謝謝！你拿到：…」並給一組**回饋代碼**（例如 `VH-7K2Q-…`），好處在這台電腦／這個瀏覽器自動解鎖

## 2. 字數規則（電腦版、腳本、Worker 三邊用同一套，Worker 會再檢查一次）
- 有中日韓文字：數「中日韓文字」的個數（不算空白、標點、表情符號），要 **≥16**（超過 15）
- 英文：數單字（連續的英文字母／數字算一個），要 **≥20**
- 中英混寫：兩個條件**任一個**達到就可以
- 重複灌水擋掉：同一個字連續超過 5 次只算 1 次（「好好好好好好好…」不算數）
- 內容最多 1,000 字

## 3. 隱私
- 只送：類型、內容、電腦版／腳本＋版本、介面語言
- **不送**：你在看的網址、下載紀錄、檔名、IP（Worker 不轉、Discord 也看不到）
- 內容裡的網址會自動換成「[網址已移除]」再送
- 畫面上清楚寫「內容會貼到開發者的 Discord 頻道」

## 4. 防灌水（Worker）
- 同一個 IP：每小時最多 3 則、每天最多 10 則（只在 Worker 記次數，24 小時後自動刪）
- 內容一模一樣的（SHA-256）30 天內不再收
- 字數不夠、太長、類型不對 → 拒收並回原因

## 5. 好處
| 好處 | 怎麼拿 | 內容 |
|---|---|---|
| 🎨 限定主題配色 | 第 1 則回饋 | 電腦版新介面多 2 種配色（「極光」綠藍、「夕暮」橘紫）；腳本盾牌面板跟著換色 |
| 🏅 支持者徽章 | 依回饋次數 | 1 則＝銅、3 則＝銀、10 則＝金；顯示在電腦版首頁右上和盾牌面板 |
| 🧪 搶先試用 | 第 3 則回饋（銀） | 設定多一個「搶先試用新功能」開關；之後新功能會先標成「搶先版」只給開了的人用 |
| 🎭 Discord 身分組 | 有任何一組代碼 | 在 Discord 打 `/回饋者 代碼:VH-…` → Worker 驗證 → 給你「回饋者」身分組 |

**代碼怎麼防造假**：Worker 用一把私鑰（Ed25519）簽「第幾則、什麼時候」；電腦版和腳本內建公鑰，驗證過才算數。
誠實說明：程式在使用者自己電腦上，懂程式的人還是能改程式繞過本機的解鎖——這些好處本來就是「謝謝你」性質，不影響安全功能。Discord 身分組由 Worker 驗證，造不了假。

## 6. 你要做的設定（我會一步一步帶你）
1. Discord 開頻道 **#意見回饋**，建一個 Webhook，網址貼到 Cloudflare Worker 的設定（Secret `DISCORD_FEEDBACK_WEBHOOK`）
2. Discord 建身分組「回饋者」，把機器人的身分組拉到它上面（機器人才能給）；身分組 ID 貼到 Worker 設定 `FEEDBACK_ROLE_ID`、伺服器 ID 貼 `GUILD_ID`
3. Cloudflare 建一個 KV（記防灌水次數），綁到 Worker 叫 `FEEDBACK_KV`
4. 重貼 Worker 程式、開一次 `/register`（多了 `/回饋者` 指令）
5. 簽名私鑰：我在 GitHub Actions 產生、你從那裡複製貼到 Worker Secret `FEEDBACK_SIGN_KEY`（**不經過 AI 對話**）；公鑰寫進程式

## 7. 版本與測試
- 電腦版 v1.48.0、腳本 v3.25.0、Worker 更新
- 新的連線目的地：你的 Worker 網址 → SECURITY.md、`net_test.py` 允許清單、腳本 `@connect` 都要加
- 測試：字數規則（中、英、混、灌水）三邊結果一致；代碼驗證（真代碼過、改一個字不過）；Worker 用假 Discord 測轉送、限流、重複；腳本隱私測試確認沒送網址

## 實作
- 共用字數規則：`.github/feedback/rule.js`（腳本、`webui/app.js`、`cloudflare/worker.js` 各貼一份，`// FB-RULE-START～END`，測試檢查一模一樣）＋ `vh_feedback.py`（Python 版）；`.github/feedback/cases.json` 兩邊都要對
- 電腦版：`vh_feedback.py`（`FEEDBACK_URL`、`FB_PUBKEY`、`send`、`verify_token`、`rewards`）；設定 `fb_tokens`、`fb_pub`（第一次從 Worker 回應記下公鑰）、`fb_theme`、`beta_features`；新介面「💬 意見回饋」頁、右上徽章、`body.acc-aurora/acc-dusk`
- 腳本：`ui.actions.feedback`、`FEEDBACK_URL`／`FB_PUBKEY`（跟電腦版同一個）、`fb_tokens`／`fb_pub` 只存暴力猴（`isSecret`）、`fb_theme` → `VH_ACCENT`、`beta`
- Worker：`POST /feedback`、`GET /feedback/pubkey`、指令 `feedback-role`（zh-TW「回饋者」）；KV 鍵 `fb:key`、`rl:h:*`、`rl:d:*`、`dup:*`、`used:*`
