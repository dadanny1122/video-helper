# 五個新功能規格（電腦版 v1.48.0、腳本 v3.25.0）

使用者 2026-11-26：「都做，我晚點測試」。下面的決定都照建議，測試時覺得不對再改。
程式的共用邏輯放在 `vh_extras.py`（不碰視窗，方便測試）；測試 `.github/extras_test.py`。

> 意見回饋分支（`feature/feedback`）還沒合併；它合併時改成電腦版 v1.49.0、腳本 v3.26.0。

## 1. 🔒 開啟密碼鎖

| 項目 | 決定 |
|---|---|
| 密碼 | 4～12 位數字（PIN）；存 PBKDF2-SHA256、20 萬次、16 位元組 salt，不存原本的數字 |
| 什麼時候鎖 | 打開電腦版時；閒置超過 N 分鐘（關／5／15／30／60，預設 15）；縮到系統匣時；右上角「🔒」按一下 |
| 鎖住時 | 網頁只拿得到「鎖住畫面」需要的東西：下載紀錄、縮圖、Nexus、通知、標題都**不送**；動作只收「解鎖」 |
| 下載 | 鎖住時照常下載、瀏覽器照常可以送；Windows 通知不寫標題（「下載完成 1 部」） |
| 系統匣 | 「打開下載資料夾」鎖住時不開，改通知「先解鎖」 |
| 打錯 | 連錯 5 次 → 等 30 秒，之後每次加倍，最多 15 分鐘 |
| 改／關密碼 | 要先輸入舊密碼 |
| 誠實說明 | 這是「防別人順手打開」，不是加密：影片檔還是在資料夾裡。忘記密碼：關掉電腦版，用記事本打開設定資料夾的 `settings.json`，刪掉 `lock_pin` 那行 |
| 舊介面（WebView2 打不開時） | 打開時跳輸入框，錯 5 次就關掉 |

## 2. ⭐ 稍後下載清單

| 項目 | 決定 |
|---|---|
| 加入 | 腳本下載面板最上面「⭐ 稍後下載」→ Bridge `POST /later {url, title}`（新 feature `later`）；只收支援下載的 9 個網站 |
| 存哪 | 電腦版 `later.json`（設定資料夾），最多 300 部；同一部影片（`video_key`）不重複 |
| 看 | 下載管理頁「⭐ 稍後下載」卡片：每部 ⬇ 下載／🌐 打開網頁／✕；「⬇ 全部下載」 |
| 下載 | 一般網站 → 直接用網頁網址加入佇列（預設畫質）；網站擋程式的（Pornhub，`sites.json` 的 `needs_browser`）→ 用瀏覽器打開該頁並加上 `#vh-later`，腳本看到就自動「送到電腦版」最高畫質；一次最多開 5 頁 |
| 清掉 | 加入佇列後就從清單拿掉（不管從哪裡加入，只要是同一部） |
| 舊電腦版 | 腳本照 `desktopLacks('later')` 說「請更新電腦版」 |

## 3. 🌙 定時下載

| 項目 | 決定 |
|---|---|
| 模式 | `off` 關／`window` 只在時段內下載／`fast_night` 時段內全速、其他時間限速 |
| 時段 | 開始、結束都是整點（0～23）；可以跨半夜（預設 1:00～7:00） |
| 白天限速 | 2／5／10／20 Mbps（預設 5）；跟「速度上限」取比較小的 |
| `window` 時段結束時 | 正在下載的**暫停**（保留已下載部分），時段開始自動繼續 |
| 略過一次 | 「▶ 現在就下載」：這一批下載完（佇列空了）之前不管時段 |
| 節點 | 傳回 Master 的限速也套用同一個值 |

## 4. 🗂 自動整理資料夾

| 項目 | 決定 |
|---|---|
| 模式 | `off`／`site`（`下載資料夾\Pornhub\`）／`site_month`（`下載資料夾\Pornhub\2026-11\`）；網站名稱用 `sites.json` 的 name |
| 什麼時候 | 加入佇列時決定存哪（只改「存到預設下載資料夾」的任務）；**不搬已經下載好的舊檔** |
| 找重複 | 下載管理頁「🧹 找重複」：下載紀錄裡同一部影片（`video_key`）有 2 個以上檔案還在 → 列出；預設保留畫質最高的、勾選其他的 |
| 刪除 | 丟到**資源回收筒**（Windows SHFileOperation＋FOF_ALLOWUNDO），可以救回；不是 Windows 時不能用 |
| 紀錄 | 刪掉的那筆紀錄標「檔案已刪除」 |

## 5. 📱 下載完成通知手機

| 項目 | 決定 |
|---|---|
| 怎麼送 | 你自己 Discord 伺服器某個頻道的 Webhook（手機 Discord App 會跳通知）；不經過 Cloudflare Worker |
| 什麼時候 | 佇列全部處理完（沒有下載中、等待中、等重試）而且這一批至少完成或失敗 1 部 |
| 內容 | 只有數字：「✅ Video Helper：下載完成 3 部，共 2.1 GB（失敗 1 部）」；**不寫標題、網站、網址**；`allowed_mentions` 空 |
| Webhook 網址 | 只收 `https://discord.com/api/webhooks/數字/字串`（也收 discordapp.com、ptb.、canary.）；用 DPAPI 加密存（`SECRET_KEYS`）、不會再顯示、不匯出 |
| 測試 | 「傳一則測試」按鈕 |
| 安全文件 | SECURITY.md 資料外傳清單、`net_test.py` ALLOWED 加 discord.com |
